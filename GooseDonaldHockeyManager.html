Hockey Goose & Donald: Ice Empire

Single-file HTML5 hockey management game (Football Manager style).

Play live:
https://html5games.iofreeonline.com/GooseDonaldHockeyManager.html

The complete GooseDonaldHockeyManager.html (~100 KB) is the playable source. Upload it to this repo via GitHub:

  1. Open this repository on GitHub
  2. Click Add file → Upload files
  3. Drop your GooseDonaldHockeyManager.html (from your site or project folder)
  4. Commit

Or from a machine with git:

git clone https://github.com/jackiekfhui-lab/GooseDonaldHockeyManager.git
cd GooseDonaldHockeyManager
# place GooseDonaldHockeyManager.html here
git add GooseDonaldHockeyManager.html
git commit -m "Add full game source"
git push
