# Goose & Donald: Ice Empire

HTML5 hockey management simulation (Football Manager style) featuring Goose vs Donald.

## Play

Open `GooseDonaldHockeyManager.html` in a modern browser, or host it on any static HTTPS site.

Live example: https://html5games.iofreeonline.com/GooseDonaldHockeyManager.html

## Features

- Visual hockey rink with animated player dots and puck
- 16-team league, 82-game season + playoffs (top 8)
- Donald's team starts all-Epic — beat them to earn the trophy
- Roster: 1G · 2D · 3F starters (70% ice) + bench (30%)
- Player rarities: Common → Rare → Unique → Legendary → Epic
- Daily free player draw (+ paid / rewarded video)
- Equipment shop (stick, skate, helmet) with rarity boosts
- Economy: win $10 / draw $5 / loss $1
- Procedural unique player faces
- Auto-save (localStorage)
- Google H5 Games Ads hooks for rewarded video
